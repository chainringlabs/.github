# .github

Organization-wide defaults for Chain Ring Labs repositories. GitHub applies a
file here to any repository in the organization that does not have its own.

| File | What it provides |
|---|---|
| `SECURITY.md` | The default security policy: how to report a vulnerability privately. |

Shared CI workflows live in [chainringlabs/ci](https://github.com/chainringlabs/ci)
and the shared Renovate preset in
[chainringlabs/renovate-config](https://github.com/chainringlabs/renovate-config),
not here, so each can be versioned on its own.
